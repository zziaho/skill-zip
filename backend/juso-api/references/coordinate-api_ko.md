# 좌표제공 API

건물의 X, Y 좌표를 반환합니다. 검색 유형은 검색어가 아니라 건물의 코드를 받고, 팝업 유형은 주소와 좌표를 함께 반환합니다. 출처는 좌표제공 검색 API와 좌표제공 팝업 API 페이지(2026-11-06 저장), 가이드 PDF "[가이드]좌표검색API_활용_방법"(23쪽, 2025-12)과 "[가이드]좌표팝업API_활용_방법"(21쪽, 2026-07), 샘플입니다.

`R`, `G`, `D`는 `SKILL_ko.md`에 정의되어 있습니다.

## 좌표계

팝업 가이드는 "X,Y 좌표는 GRS80 UTM-K 기준입니다. 위도, 경도 등 변경이 필요하시면 별도의 변환작업을 하셔야 합니다."라고 밝힙니다. 이 문장이 자료에서 좌표계에 대해 밝힌 유일한 내용입니다.

- `D`: GRS80 기준 UTM-K는 EPSG:5179입니다(자료가 밝힌 내용이 아니라 일반 상식입니다). 샘플 값(서울 마포구 건물의 `entX` 945959.04, `entY` 1953851.73)이 이와 맞습니다. 검색 API의 좌표도 같은 좌표계로 취급하되, 검색 API의 가이드는 이를 밝히지 않습니다.
- 웹 지도에 점을 표시하려면 EPSG:5179 정의를 사용해 투영 라이브러리로 WGS84(EPSG:4326)로 변환합니다. 예를 들어 브라우저에서는 `proj4js`를, Java 서버에서는 `proj4j`나 GeoTools를 사용합니다. UTM-K를 직접 받는 지도 제공자는 변환이 필요 없습니다.
- 좌표가 건물의 어느 지점(중심점이나 출입구)을 나타내는지는 자료에 나와 있지 않습니다. 출입구 위치로 제시하지 않습니다(`D`).

## 검색 API

| 용도 | URL |
|------|-----|
| 서버 간 호출 | `https://business.juso.go.kr/addrlink/addrCoordApi.do` |
| JSONP | `https://business.juso.go.kr/addrlink/addrCoordApiJsonp.do` |

**요청 변수**: 도로명주소 검색 결과(또는 영문 검색, 주소 데이터베이스)에서 가져옵니다. 이름이 같습니다.

| 이름 | 필수 | 설명 |
|------|------|------|
| `confmKey` | Y | 좌표 API(검색 유형)의 승인키 |
| `admCd` | Y | 행정구역코드, 10자리 |
| `rnMgtSn` | Y | 도로명코드, 12자리 |
| `udrtYn` | Y | `0` 지상, `1` 지하 |
| `buldMnnm` | Y | 건물 본번 |
| `buldSlno` | Y | 건물 부번. 페이지는 선택이라고 적었지만 PDF는 필수라고 적었고, 없으면 `E0006`이 반환됩니다. 부번이 없으면 `0`을 보냅니다(`D`) |
| `resultType` | N | `xml`(기본값) 또는 `json` |

`keyword`, `currentPage`, `countPerPage`는 없습니다. 요청 한 번에 건물 하나를 반환합니다.

**출력**

| 구분 | 이름 | 설명 |
|------|------|------|
| common | `totalCount`, `errorCode`, `errorMessage` | 도로명주소 검색과 같습니다 |
| juso | `admCd`, `rnMgtSn`, `bdMgtSn`, `udrtYn`, `buldMnnm`, `buldSlno` | 건물의 코드 |
| juso | `entX` | X 좌표(UTM-K, 위 참조) |
| juso | `entY` | Y 좌표 |
| juso | `bdNm` | 건물명(선택) |

- 좌표는 소수 문자열입니다. 좌표가 없는 건물에 대해 무엇이 반환되는지는 자료에 나와 있지 않으므로 빈 값을 처리합니다(`D`).

**오류 코드**: 번호의 의미가 도로명주소 검색과 다릅니다.

| 코드 | 의미 |
|------|------|
| `0` | 정상 |
| `-999` | 시스템에러 |
| `E0001` | 승인되지 않은 KEY(키나 키 유형이 잘못됨) |
| `E0002` | `admCd` 누락 |
| `E0003` | `rnMgtSn` 누락 |
| `E0004` | `udrtYn` 누락 |
| `E0005` | `buldMnnm` 누락 |
| `E0006` | `buldSlno` 누락 |
| `E0007` | 짧은 시간 동안 요청이 너무 많음(짧은 시간동안 다량의 주소검색 요청). 조치는 "비정상적인 연속된 호출을 삼가하세요"입니다 |

- `E0007`은 서비스가 호출을 제한하고 있다는 뜻입니다. `D`: 이 API를 반복문으로 호출해 테이블 전체를 일괄 지오코딩하지 않습니다. 주소를 저장할 때 호출하고, 결과를 주소와 함께 캐시하며, `E0007`이 나오면 호출 간격을 늘립니다. 대량 작업에는 서비스가 내려받도록 제공하는 주소 데이터와 공간 데이터를 사용합니다.
- 좌표 검색 페이지에는 도로명주소 검색 페이지에서 복사한 검색어 필터와 페이지 나누기 예시가 나와 있습니다. 이 API에는 검색어도 페이지 나누기도 없으므로 적용되지 않습니다.

**샘플**: 컨트롤러 샘플은 `"...addrCoordApi.do?admCd ="+admCd+...`로 쿼리를 만들고(`=` 앞의 공백에 주의), `URLEncoder`를 import하면서도 아무것도 인코딩하지 않으며, 키를 요청에서 받습니다. `search-api_ko.md`의 서버 프록시 방식을 사용하되, 다섯 코드를 전송하기 전에 숫자인지 검증합니다(`admCd`는 10자리, `rnMgtSn`은 12자리, `udrtYn`은 0이나 1).

## 팝업 API

| 용도 | URL |
|------|-----|
| PC 팝업 | `https://business.juso.go.kr/addrlink/addrCoordUrl.do` |

- 흐름, 요청 변수(`confmKey`, `returnUrl`, `resultType`, `useDetailAddr`, `encodingType`), 오류 메시지는 도로명주소 팝업(`popup-api_ko.md`)과 같습니다.
- 출력에 `entX`와 `entY`가 추가됩니다. 콜백은 값 27개를 받으며, 도로명주소 팝업의 25개 뒤에 `entX`, `entY`가 따라옵니다.
- 가이드 PDF의 코드 예시는 `addrLinkUrl.do`로 제출하고 값 10개만 처리합니다. API 페이지, PDF 자체의 표, 내려받는 샘플은 `addrCoordUrl.do`와 값 27개를 사용하므로 이를 따릅니다(`D`).
- 좌표 팝업 샘플에도 다른 팝업과 같은 반사형 XSS가 있습니다. `popup-api_ko.md`의 안전한 returnUrl 페이지를 사용하되, 필드 목록에 `entX`와 `entY`를 추가하고 `addrCoordUrl.do`로 제출합니다.

## 검색과 팝업 중 선택

| 필요 | 사용 |
|------|------|
| 사용자가 폼에서 주소를 선택하고 그 좌표도 필요함 | 좌표 팝업: 한 단계 |
| 이미 검색 API를 사용하고 있거나, 코드와 함께 저장된 주소가 있음 | 저장된 `admCd`, `rnMgtSn`, `udrtYn`, `buldMnnm`, `buldSlno`로 좌표 검색 |
| 페이지에 지도 표시 | 지도 API는 이 스킬에서 다루지 않습니다 |
