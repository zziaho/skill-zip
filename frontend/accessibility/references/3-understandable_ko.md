# 3. 이해의 용이성 (Understandable)

콘텐츠와 사용자 인터페이스의 조작 방법은 사용자의 능력과 관계없이 이해할 수 있어야 합니다.

`KWCAG` 열은 KS X OT0003:2022의 항목 번호입니다. 번호가 있는 행은 `수준`과 관계없이 한국 웹 접근성을 준수하기 위한 **필수** 항목입니다. `—`는 대응하는 KWCAG 항목이 없다는 뜻입니다.

## 3.1 가독성 (Readability)

| ID | 규칙 | 검사 방법 | 범위 | 수준 | KWCAG |
|----|------|-----------|------|------|-------|
| 3.1.1 | 보조기술이 올바른 음성 엔진이나 점자 모듈을 선택할 수 있도록 페이지나 앱의 기본 언어를 선언합니다 | 웹: html 요소에 유효한 lang 속성이 있는지 확인합니다. 모바일: 앱의 언어 설정이 콘텐츠의 언어와 일치하는지 확인합니다 | WM | A | 7.1.1 |

## 3.3 입력 도움 (Input Assistance)

| ID | 규칙 | 검사 방법 | 범위 | 수준 | KWCAG |
|----|------|-----------|------|------|-------|
| 3.3.1 | 입력 오류가 발생하면 오류가 발생한 위치와 이유를 텍스트로 알려야 합니다. 초점을 오류 위치로 옮기거나 오류 요약을 먼저 보여 주면 도움이 됩니다. 시스템이나 플랫폼에서 발생한 오류에는 적용되지 않습니다 | 필수 필드를 비우거나 잘못된 값을 넣고 폼을 제출하여, 오류 메시지가 해당 필드를 지목하고 문제를 설명하는지 확인합니다 | WM | A | 7.3.1 |
| 3.3.2 | 모든 입력 필드에는 보조기술이 인식할 수 있도록 프로그램으로 연결된 레이블이 있어야 합니다. 레이블은 입력 목적을 명확하게 설명해야 합니다 | 모든 입력 필드에 레이블이 있는지 확인하고, for/id, aria-labelledby, label 요소로 감싸기 중 하나로 연결되어 있는지 확인합니다 | WM | A | 7.3.2 |
| 3.3.3 | 법률, 금융, 데이터 삭제, 시험 답안 제출처럼 중요한 제출 작업에는 최종 제출 전에 취소, 수정·검토, 확인 단계 중 하나를 제공합니다 | 결제, 삭제, 제출 절차를 실행해 보고, 실행 취소·검토·확인 대화상자 중 하나 이상의 안전장치가 있는지 확인합니다 | WM | AA | — |
