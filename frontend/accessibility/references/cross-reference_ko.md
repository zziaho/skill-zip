# 대응표: 통합 ID와 원래 표준 번호

이 참조 자료에서 사용하는 통합 ID를 한국 표준의 원래 번호, WCAG 성공 기준과 연결합니다.

## 범례

- **통합 ID**: 이 참조 자료에서 사용하는 ID입니다.
- **KWCAG 2.2**: KS X OT0003:2022(웹)의 요구사항 번호입니다. 표준 원문과 대조하여 검증했습니다. KWCAG 2.2에는 요구사항이 33개 있으며, A/AA 수준 구분 없이 33개 모두가 필수입니다. KWCAG 2.2는 WCAG 2.1을 기반으로 하며, 7.2.2, 7.3.3, 7.3.4는 이후 WCAG 2.2에서 확정된 기준을 미리 도입한 항목입니다.
- **MACAG 2025**: KS X 3253:2025(모바일)의 요구사항 번호입니다. 표준 원문과 **대조하지 않았으므로**, 인용하기 전에 반드시 확인해야 합니다.
- **WCAG SC**: W3C WCAG 2.2의 성공 기준입니다.
- `—`는 해당 표준에 적용되지 않는다는 뜻이고, `?`는 확인되지 않았다는 뜻입니다.
- 통합 ID는 내부용 번호이며, WCAG SC 번호와 **같지 않습니다**(예: 통합 1.4.1은 WCAG 1.4.2입니다). 보고서에는 KWCAG 열이나 WCAG SC 열의 번호를 인용합니다.
