# 선택 컴포넌트

값을 선택하는 KRDS 컴포넌트인 라디오 버튼, 체크박스, 셀렉트, 토글 스위치, 태그를 다룹니다. 모두 2025-01-15에 최초 등록되었습니다(Figma v1.0.0, HTML Component Kit v1.0.1). 태그의 삭제 버튼은 2025-02-04에 크기가 수정되었습니다(HTML Component Kit v1.0.3).

**규칙** 표의 강도는 `SKILL_ko.md`의 표기를 따릅니다.

## 사용할 컴포넌트 선택

| 상황 | 사용할 컴포넌트 | 출처 |
|------|-----------------|------|
| 정확히 하나를 선택하며, 옵션을 비교해야 하거나 속도가 중요함 | 라디오 버튼 | 라디오 버튼, 셀렉트 |
| 사용자가 잘 아는 7개를 초과하는 옵션 중 하나를 선택함 | 셀렉트(또는 콤보 상자) | 라디오 버튼 |
| 7개에서 20개의 옵션 중 하나를 선택하거나, 공간이 부족하거나, 모바일이 중요함 | 셀렉트 | 셀렉트 |
| 옵션이 20개를 초과함 | 일치하는 옵션을 제안하는 콤보 상자 또는 여러 개의 셀렉트 | 셀렉트 |
| 모바일 플랫폼에서 여럿 중 하나를 선택함 | 셀렉트나 콤보 상자를 먼저 고려함 | 라디오 버튼 |
| 하나 이상을 선택하며, 선택이 나중에 확정되는 더 큰 과업(신청, 제출)의 일부임 | 체크박스 | 체크박스 |
| 서로 반대인 두 부울 상태가 즉시 적용됨 | 토글 스위치 | 토글 스위치 |
| 상태를 적용하려면 별도의 제출이나 적용 단계가 필요함 | 토글이 아니라 체크박스 또는 라디오 버튼 | 토글 스위치 |
| 옵션이 계층 구조임 | 상위 항목이 중간 상태인 체크박스 목록 | 토글 스위치, 체크박스 |
| 이미 설정한 필터와 정렬 옵션을 표시하거나 삭제함 | 태그 | 태그 |
| 상호작용 없이 데이터에 레이블을 붙이거나 분류만 함 | 태그가 아니라 배지 | 태그 |

- `D`: 라디오 버튼은 "7개 초과"에서 끝나고 셀렉트는 "7개 이상"에서 시작하므로, 정확히 7개는 둘 다 해당합니다. 옵션을 비교해야 한다면 라디오 버튼을, 공간이 부족하다면 셀렉트를 우선합니다.

## 라디오 버튼 (radio button)

옵션 중 하나의 값을 선택하는 데 사용하며, 새 옵션을 선택하면 이전 선택이 해제됩니다.

- **구조**: 1 그룹 레이블(선택), 2 컨트롤, 3 옵션 레이블

**규칙**

| 규칙 | 강도 | KWCAG | 검사 방법 |
|------|------|-------|-----------|
| 옵션은 기본적으로 가나다순으로 정렬합니다. 많이 선택하는 순으로 정렬하면 더 빠를 수 있으나 편견을 강화할 수 있으므로, 뚜렷한 근거가 없다면 가나다순이 가장 안전합니다 | `G` | — | |
| 라디오 버튼은 수직으로 배치하며, 레이블이 짧을 때만 수평으로 배치합니다 | `G` | — | |
| 각 레이블은 컨트롤의 오른쪽에 둡니다 | `R` | — | 레이블이 오른쪽에 있는지 확인합니다 |
| 수평으로 배치할 때는 버튼 사이의 간격을 컨트롤과 레이블 사이의 간격보다 확실히 넓게 둡니다 | `R` | — | |
| 옵션 레이블은 분명하고 정확하게 작성합니다 | `R` | — | |
| 정확한 답변이 중요한 경우에는 특정 옵션을 미리 선택하지 않습니다 | `R` | — | 로딩할 때 `checked`가 없는지 확인합니다 |
| 해당 없음, 잘 모름, 선택 안 함 옵션의 제공을 고려합니다. 선택 항목에서는 특히 그렇습니다(선택한 라디오는 해제할 수 없습니다) | `G` | — | |
| 컨트롤은 인접 배경과 3:1 명도 대비를 갖게 합니다 | `R` | 5.4.3 (WCAG 1.4.11) | |
| 선택 상태를 색상만으로 구분하지 않습니다 | `R` | 5.4.1 색에 무관한 콘텐츠 인식 | |
| 라디오 버튼을 키보드로 조작할 수 있게 합니다. 커스텀 스타일에서도 기본 input에 `display:none`, `visibility:hidden`, `opacity:0`을 사용하지 않습니다 | `R` | 6.1.1 키보드 사용 보장 | |
| 초점을 명확하게 표시합니다. 숨긴 기본 input의 크기와 위치를 보이는 컨트롤에 맞춰 포커스링이 올바른 위치에 나타나게 합니다 | `R` | 6.1.2 초점 이동과 표시 (KRDS: "초점 이동") | |
| 각 라디오에 접근 가능한 이름(`<label>`, `title`, `aria-label`, `aria-labelledby`)을 제공합니다. 레이블을 눌러도 선택되도록 `<label>`을 우선 사용합니다 | `R` | 7.3.2 레이블 제공 (KRDS는 여기에 6.1.1을 인용하는데 복사 오류로 보입니다) | |
| 스크린 리더가 그룹 레이블을 찾을 수 있게 `fieldset`과 `legend`로 전달합니다(KRDS: "~전달할 수 있다") | `G` | — (WCAG 1.3.1, 3.3.2) | 모든 라디오 그룹이 `legend`가 있는 `fieldset` 안에 있는지 확인합니다 |
| `D`: 그룹 레이블은 필수로 취급합니다. WCAG 1.3.1은 관계를 프로그램적으로 전달하라고 요구하며, "예/아니요" 옵션 그룹은 질문이 없으면 의미가 없습니다 | `D` | — | |

**키보드**

| 키 | 동작 |
|----|------|
| Tab, Shift + Tab | 라디오 그룹에 접근합니다 |
| 방향키 ↑/←, ↓/→ | 이전 또는 다음 라디오로 이동하여 선택합니다 |
| Space | 초점이 있는 라디오를 선택합니다 |
| Click | 컨트롤이나 레이블을 누르면 선택합니다 |

**마크업**: `.krds-check-area`(전체 영역)와 `.krds-form-check`(각 옵션)가 필수이며, 선택은 `.chk-column`(세로 정렬)과 크기 `.medium`, `.large`입니다. 추가 설명은 `.krds-form-check-cnt > p.krds-form-check-p`입니다. 칩 스타일은 `label.krds-form-chip-outline`이 있는 `.krds-form-chip`입니다(선택자 표에 없습니다).

```html
<fieldset class="form-group">
  <legend class="form-tit">발급 방법</legend>
  <div class="krds-check-area chk-column">
    <div class="krds-form-check"><input type="radio" name="issue" id="issue1" value="online"><label for="issue1">온라인 발급</label></div>
    <div class="krds-form-check"><input type="radio" name="issue" id="issue2" value="mail"><label for="issue2">등기우편</label></div>
  </div>
</fieldset>
```

- `D`: KRDS의 예시는 `legend` 없이 `div.fieldset`을 사용하고, 두 그룹에 같은 `name`을 붙여서 하나의 라디오 그룹으로 합쳐 버립니다. 실제 `fieldset`/`legend`를 사용하고, 그룹마다 `name`을 하나씩 부여합니다.

## 체크박스 (checkbox)

하나 이상의 값을 선택하는 데 사용하며, 각 옵션은 서로 독립적입니다.

- **구조**: 1 그룹 레이블(선택), 2 컨트롤, 3 옵션 레이블
- **유형**: 독립 옵션(선택됨, 선택 안 됨), 하위 옵션이 있는 "전체 선택"(선택됨, 선택 안 됨, 중간 상태: 하위 항목 중 일부만 선택되면 상위 항목이 중간 상태)
- **적합한 경우**: 필터, 약관, 조건. **부적합한 경우**: 하나만 선택하는 경우(라디오 버튼), 즉시 적용되는 설정(토글 스위치)

**규칙**

| 규칙 | 강도 | KWCAG | 검사 방법 |
|------|------|-------|-----------|
| 옵션은 기본적으로 가나다순으로 정렬합니다(라디오 버튼과 같은 이유) | `G` | — | |
| 체크박스는 수직으로 배치하며, 레이블이 짧을 때만 수평으로 배치합니다 | `G` | — | |
| 각 레이블은 컨트롤의 오른쪽에 둡니다 | `R` | — | |
| 옵션 레이블은 분명하고 정확하게 작성합니다 | `R` | — | |
| "전체 선택"이 있다면 중간 상태를 명확하게 표현합니다 | `G` | — | 하위 항목 일부가 선택되지 않았을 때 상위 항목이 선택된 상태로 보이지 않는지 확인합니다 |
| 체크박스와 아이콘은 인접 배경과 3:1 명도 대비를 갖게 합니다 | `R` | 5.4.3 (WCAG 1.4.11) | |
| 선택된 상태를 색상만으로 구분하지 않습니다 | `R` | 5.4.1 색에 무관한 콘텐츠 인식 | |
| 체크박스를 키보드로 조작할 수 있게 합니다(기본 input에 `display:none`, `visibility:hidden`, `opacity:0`을 사용하지 않습니다) | `R` | 6.1.1 키보드 사용 보장 | |
| 초점을 명확하게 표시하고 보이는 컨트롤과 일치시킵니다 | `R` | 6.1.2 초점 이동과 표시 (KRDS: "초점 이동") | |
| 각 체크박스에 접근 가능한 이름을 제공하며, `<label>`을 우선 사용합니다 | `R` | 7.3.2 레이블 제공 | |
| 그룹에는 `fieldset`과 `legend`를 사용합니다(KRDS: "~전달할 수 있다". `D`: 라디오 버튼과 마찬가지로 필수로 취급합니다) | `G` | — (WCAG 1.3.1, 3.3.2) | |

**키보드**: Tab과 Shift + Tab으로 모든 체크박스에 접근하고, Space로 초점이 있는 체크박스를 전환합니다. 컨트롤이나 레이블을 Click하면 전환됩니다. 컨트롤은 크기가 작으므로 레이블까지 클릭 영역을 **확장해야** 합니다.

**마크업**: 라디오 버튼과 같은 클래스(`.krds-check-area`, `.krds-form-check`, `.chk-column`, `.medium`, `.large`)를 사용합니다.

- `D`: KRDS는 중간 상태의 마크업을 제시하지 않습니다. 기본 체크박스에는 스크립트로 `input.indeterminate = true`를 지정하고, 커스텀 체크박스에는 `aria-checked="mixed"`를 사용합니다.

## 셀렉트 (select)

옵션을 팝업으로 보여 주고 그중 하나를 선택하게 합니다.

- **구조**: 1 레이블, 2 컨테이너, 3 확장/축소 아이콘, 4 강조 효과(선택했거나 초점이 있는 옵션), 5 옵션
- **적합한 경우**: 옵션이 7개에서 20개일 때. 폼에서 값을 선택할 때. 공간이 부족하거나 모바일일 때(기본 컨트롤)
- **부적합한 경우**: 옵션을 비교해야 하는 경우(라디오 버튼). 여러 값을 선택하는 경우(체크박스, 다중 선택 드롭다운). 옵션이 20개를 초과하는 경우(콤보 상자 또는 분할한 셀렉트)

**규칙**

| 규칙 | 강도 | KWCAG | 검사 방법 |
|------|------|-------|-----------|
| 옵션 텍스트는 간결하게 작성합니다. 너비를 넘는다면 툴팁으로 전체 텍스트를 **보여 주어야** 합니다 | `R` | — | |
| 모든 셀렉트에 레이블을 제공합니다. 명확한 이유가 있을 때만 생략합니다 | `G` | — | |
| 값을 바꿀 때 폼이 제출되어서는 안 되며, 별도의 버튼으로만 제출합니다 | `R` | — (`D`: KWCAG 7.2.1 사용자 요구에 따른 실행에도 해당) | `onchange="form.submit()"`이 없는지 확인합니다 |
| 셀렉트에 접근 가능한 이름(`<label>`, `title`, `aria-label`, `aria-labelledby`)을 제공합니다 | `R` | 7.3.2 레이블 제공 | |
| 확장 아이콘은 인접 배경과 3:1 명도 대비를 갖게 합니다 | `R` | 5.4.3 (WCAG 1.4.11) | |

**키보드**

| 키 | 동작 |
|----|------|
| 컨테이너에서 Click, Enter, Space | 목록을 확장하거나 축소합니다 |
| 바깥을 Click | 목록을 축소합니다 |
| Esc | 목록을 축소하고 컨테이너로 초점을 이동합니다 |
| Tab, Shift + Tab | 모든 셀렉트에 접근합니다 |
| 방향키 ↑/←, ↓/→ | 목록이 축소된 상태에서 이전 또는 다음 옵션으로 바꿉니다 |
| 옵션에서 Enter | 옵션을 선택하고 목록을 축소합니다 |

- KRDS의 셀렉트는 기본 `<select>`이며 이 동작을 기본으로 제공합니다. 위의 모든 키를 똑같이 구현하는 경우에만 커스텀으로 다시 만듭니다.

**마크업**: `.krds-form-select`가 필수이며, 선택은 `.completed`(값 선택 완료), `.is-error`, 크기 `.small`, `.medium`, `.large`입니다. 정렬용 변형은 `title="선택"`만 있는 `.krds-form-select-sort`를 사용합니다. `D`: "선택"은 무엇을 선택하는지 알려 주지 않으므로, 눈에 보이는 레이블이나 `sr-only` 레이블("정렬 기준")을 제공합니다.

```html
<div class="form-group">
  <div class="form-tit"><label for="region">시도</label></div>
  <div class="form-conts">
    <select id="region" class="krds-form-select" aria-describedby="region_hint">
      <option value="">시도를 선택하세요</option>
      <option value="11">서울특별시</option>
    </select>
  </div>
  <p class="form-hint" id="region_hint">주민등록상 주소지를 선택하세요.</p>
</div>
```

## 토글 스위치 (toggle switch)

서로 배타적인 두 상태를 전환합니다.

- **구조**: 1 스위치(경로와 핸들), 2 레이블(상태를 적용할 대상), 3 상태 아이콘, 4 도움말(선택)
- **적합한 경우**: 서로 반대인 두 부울 상태. 기능을 켜고 끄는 경우(알림). 즉시 적용되는 변경
- **부적합한 경우**: 계층 구조의 옵션(중간 상태가 있는 체크박스 목록). 두 상태를 모두 설명할 수 있는 레이블이 없는 경우(라디오 버튼 두 개). 기본 상태가 없는 경우(토글을 사용하지 않음). 서로 반대가 아니거나 부울이 아닌 상태(라디오 버튼). 배타적인 옵션이 여러 개인 경우(라디오 버튼). 변경을 적용하려면 제출이나 적용 단계가 필요한 경우(체크박스 또는 라디오 버튼)

**규칙**

| 규칙 | 강도 | KWCAG | 검사 방법 |
|------|------|-------|-----------|
| 레이블은 가능하면 명사형으로 작성합니다. 명확하지 않다면 동사형을 쓰거나 도움말을 추가하여 켜고 끌 때의 효과를 분명하게 알 수 있게 합니다 | `R` | — | |
| 두 상태에서 레이블을 똑같이 유지합니다. 상태는 핸들의 위치와 아이콘으로 나타내며, 상태 텍스트가 있다면 스위치 옆에 둡니다 | `R` | — | 전환해도 레이블 텍스트가 바뀌지 않는지 확인합니다 |
| 레이블은 스위치와 가깝게 두며, 넓은 컨테이너에서는 스위치 바로 옆에 둡니다 | `G` | — | |
| 한 화면의 모든 스위치에 같은 레이아웃을 사용합니다. 하나가 상태 텍스트나 아이콘을 보여 주면 모두 보여 줍니다 | `R` | — | |
| 경로, 핸들, 상태 아이콘은 인접 배경과 3:1 명도 대비를 갖게 합니다 | `R` | 5.4.3 (WCAG 1.4.11) | |
| 스위치를 키보드로 조작할 수 있게 합니다(기본 input에 `display:none`, `visibility:hidden`, `opacity:0`을 사용하지 않습니다) | `R` | 6.1.1 키보드 사용 보장 | |
| 초점을 명확하게 표시하고 보이는 스위치와 일치시킵니다 | `R` | 6.1.2 초점 이동과 표시 | |
| 스위치에 접근 가능한 이름(`<label>`, `aria-label`, `aria-labelledby`)을 제공하며, `<label>`을 우선 사용합니다 | `R` | 7.3.2 레이블 제공 | |
| 도움말을 `aria-describedby`로 연결합니다 | `G` | — (WCAG 1.3.1) | |

**키보드**: Tab과 Shift + Tab으로 모든 스위치에 접근하고, Space로 전환합니다. 스위치나 레이블을 Click하면 전환됩니다. 레이블까지 클릭 영역을 **확장해야** 합니다.

**마크업**: `.krds-form-toggle-switch`가 필수이며, 선택은 크기 `.medium`, `.large`입니다. 눈에 보이는 스위치는 레이블 안의 `span.switch-toggle > i`입니다.

```html
<div class="krds-form-toggle-switch">
  <input type="checkbox" id="noti" role="switch" aria-describedby="noti_hint">
  <label for="noti"><span class="switch-toggle"><i></i></span>알림 수신</label>
</div>
<p class="form-hint" id="noti_hint">신청 처리 결과를 문자로 받습니다.</p>
```

- `D`: KRDS의 예시는 일반 체크박스입니다. 스크린 리더가 "선택됨" 대신 "켜짐/꺼짐"으로 읽도록 `role="switch"`를 추가합니다. KRDS는 이를 언급하지 않습니다.

## 태그 (tag)

키워드로 콘텐츠를 분류하거나, 목록에서 어떤 분류나 속성이 선택되었는지 보여 줍니다.

- **구조**: 1 레이블, 2 컨테이너, 3 삭제 아이콘, 4 일괄 액션 버튼, 5 "더 보기" 버튼
- **유형**: 단순 레이블(상호작용 없음, 데이터 항목에 표시), 선행 체크 아이콘과 레이블(상호작용하는 필터 또는 정렬 옵션이며, 해제하면 단순 레이블로 돌아감), 레이블과 삭제 아이콘(이미 설정한 필터나 정렬 옵션을 해제)
- **적합한 경우**: 필터와 정렬 옵션을 표시하고 삭제하는 경우. **부적합한 경우**: 상호작용 없이 레이블만 붙이는 경우(배지)

**규칙**

| 규칙 | 강도 | KWCAG | 검사 방법 |
|------|------|-------|-----------|
| 레이블은 정확하고 간결하게 작성합니다. 두 단어 이내로 하며 줄 바꿈이 없어야 합니다 | `R` | — | |
| 태그가 어느 항목을 설명하는지 분명하도록 해당 항목 옆에 배치합니다 | `R` | — | |
| 상호작용하는 태그와 상호작용하지 않는 태그를 한 그룹에 섞지 않습니다 | `R` | — | |
| 태그를 지나치게 많이 사용하지 않으며, 적게 시작해서 사용자 의견에 따라 늘립니다 | `R` | — | |
| 색상을 지나치게 많이 사용하지 않습니다. 한 가지 색이 가장 좋고, 색을 추가한다면 의미가 있어야 하며 동등하게 강조되어야 합니다 | `R` | — | |
| 상호작용하는 태그의 초점은 3:1 명도 대비를 갖는 윤곽선으로 표시합니다 | `R` | 6.1.2 초점 이동과 표시 (KRDS: "초점 이동") | |
| 상호작용하는 태그에 기능이나 상태를 제공합니다. 필터 전환에는 `aria-pressed="true/false"`, 삭제 버튼에는 `aria-label="[태그 레이블] 옵션 삭제"`, 필터를 추가하는 태그에는 `aria-label="[태그 레이블] 필터 옵션 추가"`를 사용합니다 | `R` | — (WCAG 4.1.2) | |
| 태그의 색상으로 의미를 전달하지 않습니다 | `R` | 5.4.1 색에 무관한 콘텐츠 인식 | |
| 태그 레이블과 아이콘은 인접 배경과 3:1 명도 대비를 갖게 합니다 | `R` | 5.4.3 (KRDS는 여기에 5.4.1을 인용합니다. WCAG 1.4.3, 1.4.11) | |

**키보드**

| 조작 | 동작 |
|------|------|
| 태그 그룹으로 Tab | 첫 번째 태그에 초점이 가며, 그룹에서는 한 번에 태그 하나만 키보드 초점을 가집니다 |
| 필터 태그에서 Click, 또는 Space/Enter(keyup) | 조건을 추가하고, 초점은 적용된 필터를 보여 주는 막대로 이동합니다 |
| 토글 태그에서 Click, 또는 Space/Enter | 선택 상태를 전환하고 초점은 그대로 둡니다 |
| 삭제 버튼에서 Click, 또는 Space/Enter | 태그를 삭제하고, 초점은 이전 태그로 이동하며 남은 태그가 없으면 태그 목록 컨테이너로 이동합니다 |

**마크업**: `.krds-tag-wrap`(그룹)과 `.krds-btn-tag`(태그)가 필수이며, 선택은 크기 `.large`, `.medium`, `.small`과 링크 스타일 `.link`(`<a>`)입니다.

```html
<div class="krds-tag-wrap medium">
  <span class="krds-btn-tag">서울특별시
    <button type="button" class="btn-delete" aria-label="서울특별시 옵션 삭제"></button>
  </span>
</div>
```

- `D`: KRDS의 예시는 모든 삭제 버튼의 이름을 "삭제"(`sr-only`)로 붙여 KRDS 자신의 `aria-label` 규칙을 어기며, `aria-pressed` 예시도 없습니다.
